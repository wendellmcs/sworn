Quatro regras para trazer uma ideia de fora

1 · Instrução vira programa

Onde o original pede “confira”, o sworn confere

Um script verifica caminho, comando e prova. Não depende de a IA lembrar.

2 · Conselho vira trava

Onde o original sugere, o sworn barra

A ação só passa quando a prova aparece na resposta.

3 · Nenhuma dependência

Nada de terceiros é instalado no seu projeto

A ideia é reescrita por dentro, e um teste reprova se alguém importar código de fora.

4 · Licença respeitada

Licença restrita: só a ideia, nunca o código

Projetos de uso não comercial ou de licença fechada inspiram, mas não são copiados.

Estas são as quatro regras que transformam uma ideia de fora em recurso do sworn. Primeiro: o que no original é um pedido ao modelo vira um programa que confere. Segundo: o que é conselho vira trava. Terceiro: nada de terceiros é instalado; tudo é reescrito, e um teste automático garante isso. Quarto: a licença de cada projeto é respeitada, e quando ela é restrita só a ideia entra.
