Como começar

Três passos, uma vez por computador e por projeto

1

Adicionar a loja

claude plugin marketplace add wendellmcs/sworn

Diz ao Claude Code onde o sworn está publicado.

2

Instalar o plugin

claude plugin install sworn@sworn-local

A atualização automática vem desligada: você escolhe quando trocar de versão.

3

Apresentar o projeto

/sworn:init

O sworn olha o projeto, mostra o que entendeu e faz 6 perguntas que só o dono responde.

Depois disso não há mais nada a fazer: as travas, os avisos e as rotinas passam a agir sozinhos em cada sessão.

O que o sworn não faz, e os limites de qualquer ferramenta deste tipo, estão no guia, na seção “O que o sworn não promete”.

Instalar é simples. Os dois primeiros comandos são digitados uma vez no computador. O terceiro é dado dentro do Claude Code, uma vez por projeto: o sworn examina os arquivos, mostra o que entendeu e pergunta o que nenhuma varredura descobre, como qual comando prova que o trabalho está pronto e quem decide. A partir daí, tudo o que vimos acontece sozinho. A atualização automática vem desligada de propósito, para nenhuma versão nova mudar o comportamento no meio do trabalho.
