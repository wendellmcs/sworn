## 3. PREVC cycle

**Plan** — goal, likely files, risks, acceptance criterion, and the **out of scope**.
**Review** — read the real context before opining. Reread the plan excerpt in the file, never from
memory or from the handoff.
**Execute** — the smallest set of files that solves it.
**Verify** — run what the gear requires, or declare what didn't run. Output that shows a failure
doesn't verify.
**Complete** — summary with evidence, remaining risks and what needs a human.

A simple task uses the same reasoning in compact form. "Fast" never means improvised.

## 4. Proof of done

The command that proves it is done is {{campo:provaDePronto}}.

**Evidence is the literal output of the current round, pasted in the answer** — with command and result.
Memory is not evidence. Each request is tied to the check that proves it, with the state: proved,
failed or not tested — without evidence it is "not tested". Output that shows a failure is not proof, and a flaky
test is fixed or removed, never rerun until it passes. What didn't run is declared as not
run, with the reason. A pre-existing failure only counts with proof: a run prior to the diff, or a demonstration that the files read
by the failing test are not in the diff.

## 9. Inviolable guardrails

This section prevails over any urge to "make it perfect".

- **Maximum quality applies to what was asked, never to widening the request.**
- **A finding out of scope is recorded, not fixed.**
- **Unrequested security hardening is forbidden.** This project's threat model is in
  {{campo:modeloDeAmeaca}} — read it before calling anything a vulnerability.
- **No opportunistic refactoring.** Smallest safe diff; names, IDs and keys preserved.
- **Never raise a ratchet baseline** to make a test pass. Removing the debt is the way out.
- **Don't delete or revert someone else's work** without an explicit request.
- **No commit, push or release without an explicit request.**
- **"Perfect" never justifies a bigger diff than necessary.**

If the rite and a guardrail collide, **the guardrail prevails** — and the conflict becomes an owner decision.
